Conexión (Firebase)

Pegá acá el bloque de configuración que te dio Firebase (el que empieza con const firebaseConfig = {'{'}). Todos deben pegar exactamente el mismo.

¿No sabés dónde conseguir esto? Ver guía
  1. Andá a console.firebase.google.com y creá un proyecto gratis.
  2. Dentro del proyecto, creá una app "Web" (ícono </>).
  3. Copiá el objeto firebaseConfig que te muestra y pegalo arriba.
  4. Activá Firestore Database (modo producción) y Authentication → Anonymous.
  5. En Firestore → Reglas, pegá: allow read, write: if request.auth != null;
